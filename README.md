# BitNet On-Device Material AI (Flutter Android)

[![Build Android APK](https://github.com/Artjom777/bitnet-mobile-flutter/actions/workflows/build-apk.yml/badge.svg)](https://github.com/Artjom777/bitnet-mobile-flutter/actions/workflows/build-apk.yml)

Мобильное приложение на **Flutter** для Android с реализацией дизайна **Material Design 3 (Material You)**, оптимизированное для автономного локального инференса нейросетей на базе ядра **bitnet.cpp** (троичное 1.58-битное квантование {-1, 0, +1}).

---

## 📱 Экраны и функционал

### 1. Чат (`ChatScreen`)
* **Интерактивный диалог:** Полноценная отправка сообщений и потоковая (стриминговая) генерация ответов локальной нейросетью.
* **Статус-баннер инференса:** Отображение текущей активной модели (`BitNet b1.58 3B Int2/TL1`), офлайн-статуса, используемых потоков CPU, скорости (`31.2 tok/s`) и шкалы занятой оперативной памяти (RAM).
* **Блок кода с подсветкой синтаксиса:** Отображение файлов (например, `parser.py`), подсветка ключевых токенов Python и кнопка копирования в буфер обмена.
* **Быстрые запросы (Quick Prompts):** Горизонтальный скролл чипов («Код на Python», «Объясни квантование», «Анализ логов», «Сгенерируй идею») для мгновенной подстановки в поле ввода.
* **Material 3 Floating Input Dock:** Поле ввода, кнопки прикрепления контекста, голосового ввода и отправки.

### 2. Модели (`ModelsScreen`)
* **Список локальных моделей:** Карточки с архитектурой, форматом (`.tl1`, `.gguf`), размером, размером контекста и статусом («В памяти», «Готова», «На диске»).
* **Управление памятью:** Загрузка модели в NPU/RAM и безопасная выгрузка из памяти с пересчетом системных метрик.
* **Оптимизация ядра:** Индикатор аппаратного ускорения AVX2 / ARM NEON I8MM.
* **Импорт моделей:** Загрузка весов из памяти устройства (SAF) или по прямой ссылке с Hugging Face.
* **Floating Action Button (FAB):** Быстрый переход к экрану импорта моделей.

### 3. Мониторинг (`MonitoringScreen`)
* **Спидометр генерации LIVE:** Текущая скорость генерации токенов с живым джиттером, время до первого токена (TTFT 85 мс).
* **Анимированный эквалайзер:** Живой 14-полосный спектроанализатор активности троичных ядер.
* **Метрики ОЗУ:** Сравнение расхода памяти BitNet 1.42 ГБ против FP16 6.80 ГБ (экономия более 78%).
* **Аппаратные датчики:** Температура процессора (34.2°C), аппаратные инструкции `GEMM ADD` (сложение весов без умножения).
* **Потоки CPU:** Индивидуальная загрузка ядер Cortex-X4 Prime и Cortex-A720 Perf.
* **Консоль логов bitnet.cpp:** Живой вывод сообщений движка с кнопкой копирования логов.
* **Переключатели оптимизации:** Фиксация частоты CPU, энергосберегающий режим, фоновая работа.

### 4. Настройки (`SettingsScreen`)
* **BitNet Low-Rank Tuning:** Тонкая калибровка параметров движка под процессоры Snapdragon & MediaTek Dimensity.
* **Параметры CPU:** Слайдер потоков (1–8 ядер), включение ARM NEON + I8MM, выбор размера KV-кэша (2048, 4096, 8192).
* **Гиперпараметры генерации:** Слайдеры Temperature, Top-P, Repetition Penalty.
* **Системный промпт:** Редактируемый промпт ассистента со счетчиком символов.
* **Безопасность и автономность:** 100% офлайн-режим (Air-gap), Wakelock (предотвращение засыпания CPU), выбор рабочей директории.
* **Применение настроек:** Всплывающие уведомления (Floating Toast) и сброс значений по умолчанию.

### 5. Выбор весов модели (`FilePickerScreen`)
* **Системный диалог выбора файлов:** Навигация по внутреннему накопителю, SD-карте и облачным дискам.
* **Фильтрация по форматам:** `.tl1` (BitNet 1.58b), `.gguf` (Ternary), `.bin`.
* **Проверка совместимости:** Валидация сигнатур, архитектуры и объема оперативной памяти перед загрузкой.
* **Анимация верификации:** Индикатор проверки целостности весов.

## 🎨 Дизайн-система (Material Design 3)

Приложение полностью построено на дизайн-токенах из спецификации `DESIGN.md`:
* **Surface Background:** `#131316` (глубокий темный фон)
* **Primary (Electric Indigo):** `#BDC2FF` / `#7B88FF`
* **Secondary (Pastel Teal):** `#74D7C8` / `#018376`
* **Tertiary (Luminous Violet):** `#D4BBFF` / `#9F87CB`
* **Surface Containers:** От `Lowest (#0E0E11)` до `Highest (#353438)`
* **Типографика:** Стандартные пропорции Material 3 с моноширинными метками JetBrains Mono / monospace для технических телеметрических данных.

## ⚙️ Сборка APK на серверах GitHub Actions

Сборка приложения полностью автоматизирована в `.github/workflows/build-apk.yml`:
1. При каждом `git push` в ветку `main` или ручном запуске через `workflow_dispatch` запускается виртуальная машина `ubuntu-latest`.
2. Устанавливается Java 17 и Flutter SDK (stable).
3. Собираются два APK-файла:
   - **Release APK:** `build/app/outputs/flutter-apk/app-release.apk`
   - **Debug APK:** `build/app/outputs/flutter-apk/app-debug.apk`
4. Файлы автоматически загружаются в артефакты сборки (Artifacts) и публикуются в релизах GitHub Releases.

### Как скачать готовый APK:
1. Откройте вкладку **[Actions](https://github.com/Artjom777/bitnet-mobile-flutter/actions)** в репозитории.
2. Выберите последнюю сборку в списке.
3. В разделе **Artifacts** внизу страницы скачайте `bitnet-ai-release-apk` или `bitnet-ai-debug-apk`.
4. Или перейдите в раздел **[Releases](https://github.com/Artjom777/bitnet-mobile-flutter/releases)** и скачайте установочный `.apk`.
